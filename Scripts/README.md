# لینک بازدید و صف لینک کوتاه

## فیلدهای روی `MapPoints`

| فیلد | توضیح |
|---|---|
| `VisitLink` | لینک کامل نقشه (خودکار) |
| `ShortVisitLink` | لینک کوتاه — فقط اگر ساخته شود ذخیره می‌شود |

## صف `ShortLinkQueue`

فقط یک ستون: `PointId`. لاگ و خطا ذخیره نمی‌شود. اگر لینک از قبل باشد، دوباره صف نمی‌شود.

برای دیتابیس فعلی این را اجرا کنید: `006_SimplifyShortLinkQueue.sql`
